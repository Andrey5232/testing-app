Паспорт системы: BaaS Platform (Backend-as-a-Service)

Наименование системы

BaaS Platform — облачная платформа для аутентификации и профилей.



Назначение

Предоставление готового API для управления пользователями и их профилями.

Позволяет клиентским приложениям (например, Survey Website) не писать

собственный бэкенд, а использовать единый защищённый сервис.



Основные функции

Регистрация нового пользователя по email и паролю.

Аутентификация пользователя (login) с выдачей JWT-токена.

Генерация и валидация JWT-токенов.

Получение профиля пользователя по ID.

Редактирование профиля (display\_name).



Входные данные (что принимает)

От клиентских приложений:

email, password — при регистрации и логине;

userId, JWT-токен — при запросе профиля;

display\_name — при редактировании профиля.



Выходные данные (что отдаёт)

Клиентским приложениям:

user\_id, access\_token, expires\_in — после успешного логина;

JSON профиля (id, display\_name, created\_at) — по запросу;

HTTP-коды ошибок (400, 401, 404, 500).



Внешние системы, с которыми взаимодействует

Survey Website — основной потребитель API.

База данных BaaS (проектируется в Лабе №3): таблицы users и profiles.



Ограничения и допущения

Все запросы только по HTTPS.

Пароли хранятся в виде хеша (bcrypt/argon2).

JWT имеет время жизни 1 час.

Один пользователь = один профиль.



Целевые пользователи

Клиентские веб-приложения (в данном проекте — Survey Website).

Разработчики, желающие быстро подключить аутентификацию без своего бэкенда.
