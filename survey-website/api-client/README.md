\# survey-api-client



Модуль-адаптер сайта-опросника для взаимодействия с BaaS-платформой.



\## Методы

\- `login(email, password)` — авторизация

\- `register(email, password)` — регистрация

\- `getProfile(userId, token)` — получение профиля



\## Base URL

По умолчанию: `http://localhost:5000/api`
